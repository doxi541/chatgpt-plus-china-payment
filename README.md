## 中国大陆四种付款路径，前提和失败点

中国大陆不在 OpenAI 官方支持地区名单中，官网不支持面向中国大陆的支付宝、微信直付。下面四种方式都不改变 OpenAI 的地区规则，能不能长期用，取决于账号资格和支付渠道，不取决于代充商家怎么说。

### 路线一：海外银行卡官网直付

适用条件是本人和发卡银行都在 OpenAI 支持地区。国内银行卡不行，包括国内银行发行的双币 Visa、Mastercard。卡需要支持线上国际交易、周期订阅，并能完成 3D Secure 验证；账单地址要与银行记录一致。被拒时先查卡资料、余额、发卡地和银行对周期交易的限制，不要靠编造账单地址反复试卡。

### 路线二：支付宝买美国区 Apple 礼品卡，在 iPhone 内购

需要 iPhone 或 iPad、符合地区规则的 Apple 账户，以及地区匹配的礼品卡。美国礼品卡只能兑换到美国区 Apple 账户，Apple 账户负责付款，ChatGPT 账号负责使用。步骤是先确认 App Store 当前登录账户的地区，再到支付宝里找美国区 App Store & iTunes 礼品卡，按 App 内显示的含税总额买够面额，兑换后从官方 ChatGPT App 内购。买完到 iPhone“设置 → 订阅”核对，已扣费仍显示 Free 时用 Restore purchases，不要立刻重买。

### 路线三：虚拟国际卡

开卡前要问清真实发卡银行、发卡国家、实名条件、是否支持国际周期支付和 3DS、开卡费/月费/充值费/汇损/拒付费各多少、余额怎么提现。没有经核对的固定卡商可以承诺“必过”，凡是打包票的都值得警惕。付款后分别查看 ChatGPT 账单和卡商交易记录；不再使用时先在 ChatGPT 取消订阅，再处理卡内余额，只锁卡不等于取消订阅。

### 路线四：第三方代充到本人账号

代充是把自己的 ChatGPT 账号交给第三方开通，不是买一个新号。这类商品一般要求账号处于 Free 状态，不能覆盖已有 Plus；已有订阅要等它结束、账号回到 Free 再下单，具体条件以下单页为准。流程通常是：下单并用支付宝付款，在浏览器登录要升级的 ChatGPT 账号，打开 ChatGPT 的 Session 接口页（路径 `/api/auth/session`）复制整段内容，粘贴到订单页提交，等待开通，再回原账号设置里核对 Plus。

## 常见问题

**支付宝能直接付吗？** 不能。OpenAI 官网不支持面向中国大陆的支付宝、微信直付。支付宝能买到的是美国区 Apple 礼品卡，付款发生在 Apple 侧，不是 OpenAI 官网。

**国内双币 Visa/Mastercard 行不行？** 不行。国内银行发行的双币卡不能在官网直付，即使卡面上有 Visa 或 Mastercard 标志。

**能年付吗？** 不能。目前只支持按月计费，也不能一次预付多个月。

**退款要多久？** 需要提交申请，获批后通常在 **5–10 个工作日**内处理。申请时要登录与 Plus 或 Pro 关联的 ChatGPT 账号，收据邮箱可能和账号邮箱不同。

**扣款了还显示 Free 怎么办？** 先核对 ChatGPT 账号邮箱和登录方式。用 Apple 注册并选了 Hide My Email 的，账号可能是 `@privaterelay.appleid.com` 地址，要用同一 Apple 账户点 Continue with Apple 登录。iOS 或 Android 在设置里点 Restore purchases 同步订阅。确认邮箱和登录方式后，退出当前设备再重新登录关联账号。仍然不行，联系支持并提供收据或扣款卡后四位。

**怎么取消？** 登录 ChatGPT，点头像进入 Settings，选 Account，确认登录的是关联 Plus 或 Pro 的账号，再按取消订阅的入口操作。

**代充安全吗？** 需要提交 Session，等于交出登录凭据；商家称开通后删除，但这不改变凭据已经离开你账号的事实。账号需要是 Free，已有 Plus 不能覆盖。服务方是独立第三方，不是 OpenAI 官方或授权合作方。

**听说以后 ChatGPT 和 Codex 的额度要合并计算？** 有第三方摘要称，从 12 月起 Plus、Pro、Business 的用量额度将由 ChatGPT 与 Codex 共用、按 token 计量。这一说法没有出现在本次查到的 OpenAI 官方套餐页和帮助中心页面里，具体生效日期和各档额度也未公布。当成待观察的变更，不要按它计算现在够不够用。
